Input/output separation
Original bytes, including AFTER, are hash verified first. Before engine admission,
only AFTER's top-level started_ms/finished_ms/owner_binding envelope is decoded;
unknown value spans are skipped lexically without constructing expected outcomes.
This supplies a hash-bound upper transaction cut for BOTH native hit and damage
producers. Expected outcome objects are decoded only AFTER actual API execution.
The damage producer must agree with redundant hit/source SpellId, caster/owner,
story/GUID, chronology and completeness/error flags. Its missing target UUID is
disclosed as a GUID/story inference through the unique direct hit, never fabricated.

The source compiler consumes BEFORE level/proficiency/casting ability. Native
attack/damage totals never manufacture compiler inputs. The explicit selected-d20
result seam does not reconstruct an ordered pair or discarded face16. Direct
individual damage faces require qualified one-die descriptors and no rerolls.

Comparisons use the actual immutable AttackResolutions entry: natural, requested
mode, totalUsedForComparison and armorUsedForComparison versus native stored
NaturalRoll/Total/Difficulty. These names describe comparison operands; they do
not causally decompose an effective bonus. Typed native damage packets are compared
to actual typed damage events, so unexpected Cold damage cannot match Fire by
sharing a numeric total. HP/AP/raw+usable movement/position/status comparisons
remain separate. Known target-status projection exclusions stay explicit and keep
full-scene admission blocked even when all admitted comparisons match.

Staleness is not hidden by checkpoint inheritance. Profiles must explicitly bound
latest checkpoint age AND each actor/target resource field-source age separately
before/after. Reports retain both clocks, full base chains and consumed source
locations. Every resource age must satisfy0<=age<=its explicit limit. Checkpoints
require explicit integer begin_t/end_t with begin_t==row.t<=end_t<=boundary;
missing completion never defaults to the start. A parent must complete by the
child START, not merely by the child completion. Sample st may legitimately lie
after row.t within the validated capture interval; future embedded timestamps
beyond read completion refuse. Status supplements have their own finite limits and preserve their
non-atomic/session/generation restrictions. A present null/malformed/failed exact
raw_resource_entries facet refuses; only an ABSENT facet permits explicitly
qualified checkpoint fallback. Native raw and usable movement remain distinct.

Explicit runtime selection
Default runs retain the original simulator pin. To test another reviewed frozen
runtime, build a separate adapter against that copied DLL, then pass BOTH
--adapter /absolute/path/to/TrialReplay.dll and --simulator-sha256 EXACT_LOWERCASE_SHA256.
No newest-file or shared-build lookup occurs. Relative adapter paths resolve
against the caller working directory. --adapter alone retains the default hash;
an explicit hash without an explicit adapter is refused. No installation or
shared source/build mutation is performed.
The selected hash is used by prelaunch adjacent-DLL verification, the immutable
operand request and the inside-process loaded-assembly receipt check. Reports
retain the selected adapter path, expected hash and observed binary hashes.
Selecting a hash proves identity, not API compatibility or fidelity. Validate
the owner-provided snapshot and rerun the same capture before adopting a pin.
Strict input refusal still returns before invoking either runtime.

Executed Fire Bolt miss intake
-----------------------------
A complete, singular numerical SpellCastEvent can qualify a miss even when
SpellCastTargetHitEvent and GUID-bound BeforeDealDamage are absent. This route
requires exactly DamageFlags(Miss,Dodge), native zero total with DamageType None,
a complete single ranged-spell D20 roll without rerolls, matching requested and
executed source/GUID, an independent GUID/story/source lifecycle witness joining cast/caster/target
entity identities across every relevant readable lifecycle observation, and
unique raw UsingSpellOnTarget/CastedSpell evidence in the bound transaction.
Same-GUID executed event ambiguity, contradictory positive lifecycle stories,
incomplete relevant lifecycle reads, or any GUID-bound damage producer refuses.
Preexecution story0 permits the recorded Osiris/default-ability to requested
source transition only before execution and before requested-source adoption.
Ordered reads must not regress from execution story to0, from requested source
to the initial source, or backward through the qualified ValidationStart,
MovementSteering, LogicExecutionUpdate, Finished phase sequence. No timestamp
is inferred for lifecycle reads. The attack additive descriptor must be a signed32 integer;
it remains metadata and never overrides compiled attack modifiers.
Unrelated global damage is retained in the stream and cannot be reassigned by
timestamp. The random tape contains only the native selected d20; no synthetic
D10 or zero-damage operand is supplied. Native totals, flags and difficulty are
outcome/route qualification, not calculation overrides.

After the actual API executes, positive action.no_damage=true with absent
conflicting damage/total_damage fields, the native miss total, and unchanged
target HP/temp HP corroborate the bounded zero-damage comparison. Missing
outcome fields alone never establish zero damage. Unsupported critical misses,
other miss flag combinations and ambiguous events fail closed.

When present, resources.MovementObservation.usable_projection supplies the
unrounded Guard projection for usable-movement comparisons. It must be valid,
agree with its unrounded raw observation, mask flag, rounded legacy projection,
and captured raw resource pool. Rounded consistency mirrors the producer
floor(x*10+0.5)/10 operation; the comparison operand stays unrounded.
Failed/malformed present observations refuse;
only absent observations retain the historical rounded comparison. This is a
Guard projection, not proof of movement legality or collision equivalence.
