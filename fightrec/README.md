# fightrec

FightRec v2, the fight recorder: `FightRec.lua` (the deployable copy) and its project in `recorder-project/` (source,
schema, tests, reviews, live reports). It is the only recorder; the fightbot (`../fightbot/`) reads its files.

`samples/` holds the early schema-1 test fights (Nautiloid, 2026-10-22); `chapel-recapture-2026-10-23.zip` the
chapel capture, whose first hit is the fightbot reader's test fixture.
