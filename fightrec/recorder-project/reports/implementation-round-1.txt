OPEN LIMITATIONS / GATES (not fixed; explicit)
- No live run: SE version loaded, API behaviour (multi-return GetPosition, enum representation, AppendFile and
  LoadFile semantics incl. missing-file behaviour of the collision probe, HandleToInteger, Defer timing, object
  lifetimes), coverage and cost are all unverified (docs/LIVE-CHECKLIST.txt).
- Append mode exists but is off; needs W-03 live scratch verification before APPEND_SEMANTICS_VERIFIED=true.
- No hot unsubscribe: replacing a generation requires a Lua lifecycle reset; a baseline loaded AFTER v2 in the
  same Lua state cannot be prevented by v2.
- No durability/atomicity guarantee: active part, append tail and queue are lost on crash/reset; SaveFile
  rewrite is not atomic. Session and client combatlog streams have no validated final flush hook.
- Seals/flushes are synchronous in Tick (bounded by C + one record); start/end snapshots and the GameStateChanged
  flush run inside callbacks. Bounded is not a frame-time guarantee. Host-disk single-tick maxima up to 571 ms
  (v2) and 101 ms (baseline) were observed offline, cause undetermined (live gate T-03).
- No-overwrite is a single-writer check-then-write (LoadFile probe), not an exclusive create.
- Overlapping party combats share one stream (scope_transition, unsupported). Name/stat caches grow with distinct
  identities (O(U)).
- Defaults cost more than the baseline in bytes on disk (~3.4x synthetic), host CPU per event and allocation at
  small E; checkpoint cadence untuned.
- Dice: individual die values inside ConditionRoll.Roll not copied in the pinned Result copy; RollResult is not
  a numerical stream. Status source/cause not captured. No full miss/save/RNG/AI coverage.
- Experimental functor capture: minimal, disabled by default, not production-enabled.
- Validator memory O(largest stream), not bounded; legacy XYZ unrecoverable; historical producer unknown.
- Source identity: a stamp is a build-time claim; artifact hash must be recorded externally.
